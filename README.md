# espfc_flasher
A browser flasher for esp-fc (ESP32 flight-controller firmware). Pick a dev kit, flash it over USB with Web Serial, then configure it in Betaflight Configurator 10.10.  Supported chips: ESP32, ESP32-S3, ESP32-S2 (experimental), ESP32-C3 (experimental), ESP8266 (obsolete). Works in desktop Chrome or Edge.
